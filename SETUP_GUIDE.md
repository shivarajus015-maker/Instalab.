# InstaLab Master Production App v6 — Setup & Launch Guide
1. Paste `apps_script_master_api.gs` into Google Apps Script (Extensions -> Apps Script) and Deploy as Web App (`Anyone`).
2. Paste the Web App URL into `app-config.js`.
3. Add `assets/logo-kn.png`, `assets/logo-en.png`, `assets/icon-192.png`, `assets/icon-512.png`.
4. Upload to Cloudflare Pages and test Grades 6–10 bottom filter bar + topic spelling search.
